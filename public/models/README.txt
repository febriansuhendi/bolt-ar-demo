Place your 3D product models here as .glb files.

This project expects two models:

  sail.glb            -> used when target index 0 (sail) is detected
  payung-sekaki.glb   -> used when target index 1 (payung-sekaki) is detected

They are served at:
  /models/sail.glb
  /models/payung-sekaki.glb

If a model is missing or fails to load, a colored cube placeholder is shown
for that target so the rest of the AR experience keeps working.
